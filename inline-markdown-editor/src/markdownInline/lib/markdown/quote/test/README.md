# Blockquote

A quote sits on the editor background.
A bar on the left marks the quote.
The words inside the quote are a transparent gray, fainter than the words outside it.
The quote marks stay hidden.
The bar hides while a quote mark is showing.
A nested quote has a second bar, set in from the first.
From the blank line above a quote, Down moves into that quote and the quote mark stays hidden, so the line can be edited.
When a quote wraps, the next line starts in line with the quote words.
A quote that starts with `[!IMPORTANT]` has GitHub's purple bar.
The first line shows a purple icon and the word Important in place of `[!IMPORTANT]`.
The sentences under that line stay visible in the editor text color.
