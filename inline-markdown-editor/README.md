# Inline Markdown Editor

VS Code extension package for the Inline Markdown Editor.

Editor sources live under `src/markdownInline/`.

## Development

From the monorepo root:

```bash
vp -C inline-markdown-editor run build
vp -C inline-markdown-editor run test
vp -C inline-markdown-editor run verify
```

Playground: `vp -C inline-markdown-editor run dev:markdown-inline` (http://127.0.0.1:5175/).
